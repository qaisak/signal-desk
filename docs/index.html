How we work this desk

  1. Top of the table is your day. Anything in conversation floats up; overdue follow-ups are flagged. Start there.
  2. Claim before you call. Set yourself as owner so two people never hit the same account.
  3. Log every touch. Email, call, note: one line each. Status changes set a follow-up date automatically (contacted +3d, replied +1d).
  4. Briefs only for accounts you have decided to work. Flag brief=yes in accounts.csv; the next run writes a reasoned brief and deck. Read it before it goes anywhere.
  5. Fix the facts. Learned something on a call? Edit the account's blurb and data lines in accounts.csv; every later brief gets smarter.
